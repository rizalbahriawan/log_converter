Simple service to do repeating and boring tasks at work, like:
1. convert log to timesheet excel file.
2. Add bulk ESS Log
NB: currently build only for non-aj employee

Steps:
1. Login using your ESS account
2. For Converting to Excel:
   - Fill inputs (months, year, project name). Months can be chosen more than one
   - If you need duration of work as ranged random numbers, click randomize and you can set minimum and maximum duration. Otherwise, duration is set from real duration from your ESS log.
   - Click submit and it will download timesheet in excel format.
3. For Add bulk:
   - Fill mandays, date is automatically set on weekday
   - If the first row's date is changed, it automatically change next row incrementally, also set on weekday
   - Fill logs, submit
   - Warning: this will insert log to your ESS Account, so use it at your own risk
